# Triage 标签

[English](triage-labels.md) | 中文

工程 skill 使用五种规范 triage 状态角色。下表将每种角色映射到本仓库 issue 跟踪系统使用的标签。

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要 maintainer 评估该 issue |
| `needs-info` | `needs-info` | 需要报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | Issue 已完整定义，可交由 agent 处理 |
| `ready-for-human` | `ready-for-human` | Issue 需要人工实现或判断 |
| `wontfix` | `wontfix` | 不会处理该 issue |

当 skill 使用规范角色名时，采用表中对应的 GitHub 标签。
