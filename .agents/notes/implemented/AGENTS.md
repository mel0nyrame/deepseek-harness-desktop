# AGENTS.md — Implemented Agent Notes

Implemented notes describe shipped decisions in present tense. Follow the [Agent Note format](../README.md#the-file-format).

Keep paths, symbols, defaults, mechanisms, and verification evidence current with the implementation; rewrite stale facts rather than append history. A reversal or rationale change requires a new cross-linked note. Archive low-future-value notes through [`dsh-archive-agent-notes`](../../skills/dsh-archive-agent-notes/SKILL.md); consolidate a fully superseded note only under the [consolidation rule](../README.md#when-to-write-one).
