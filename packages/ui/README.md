# `@dsh-desktop/ui`

UI contributions for DSH Desktop: renderer registrations, theme tokens,
layout contributions, and slots entered through documented client extension
points. No official client package is copied into the desktop namespace; a
precise upstream patch is allowed only for a missing generic extension point.

The package currently contributes compact macOS window controls, native theme
and Reduce Transparency projection, zero-width sidebar collapse, and the
durable sidebar-material setting. Conversation, workspace, directory-picker,
and remaining settings presentation belong to decoupling 8/10.
